

## Giới Thiệu  
Đây là project giải đề thi lập trình hướng đối tượng của Học viện kĩ thuật mật mã. Project bao gồm các Packages là De1_1, De1_2, De2_1, De2_2, De3_1, De3_2, De4_2 tương ứng là các đề 1-1, 1-2, 2-1, 2-2, 3-1, 3-2, 4-2 trong đề thi chính thức.  
## Công Nghệ Sử Dụng  
- **Ngôn ngữ lập trình**: Java
- **Môi trường phát triển**: NetBeans 23  
- **Phiên bản JDK**: JDK 21
